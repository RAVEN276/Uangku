# Core Directives
1. Build robust Kotlin Jetpack Compose UIs.
2. Provide visually pleasing layouts resembling Spatial, Glassmorphism, and Bento grids (32.dp rounding) per user request.
3. **Antislop Copywriting**: Ensure all copywriting (Indonesian & English) is human, clear, and authentic. Strictly avoid empty AI vocabulary ("unlock", "elevate", "journey", "delve"), significance inflation, actorless passive voice, and fake social proof.
4. **Antislop Layout & Mobile**: Design layouts that reflow cleanly, maintain minimum 48.dp touch targets with adequate spacing, ensure zero horizontal overflow, and ensure bottom navigation never occludes content.
5. **Antislop UI & Visuals**: Apply disciplined color palettes, avoid decorative emoji in headings or buttons, cap visual accents with purpose, and maintain intentional component hierarchy.
6. **Material Design 3 Expressive**: Apply expressive principles with organic spring-based animations, tonal color harmony, friendly geometry, generous padding, and WCAG AA accessibility.
7. **Android Motion Craft**: Decide whether motion belongs before deciding how it should feel. Apply organic spring-based physics, smooth interruptibility with velocity handoff, respectful degradation for reduced animation settings, and avoid gratuitous motion.
